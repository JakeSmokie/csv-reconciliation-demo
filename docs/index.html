ВОСПРОИЗВОДИМОСТЬ
Проверьте на своих файлах
  1. Скачайте операции и выплаты из примера.
  2. Запустите скрипт по инструкции в репозитории.
  3. Сравните отчёт: суммы, статусы и SHA-256 входных файлов.

  • Расчёт в копейках через Decimal.
  • Проверку дубликатов и формата значений.
  • Исходные строки для каждой цифры.
  • Тесты ошибок и крайних случаев.
