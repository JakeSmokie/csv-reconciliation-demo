Какой формат CSV нужен
Ожидаемые операции
id,gross,commission,refund
T001,1000.00,100.00,0.00
Выплаты
id,actual_net
T001,900.00

UTF-8, разделитель — запятая. Суммы с точкой, до двух знаков после неё. ID должны быть уникальными в каждом файле.
